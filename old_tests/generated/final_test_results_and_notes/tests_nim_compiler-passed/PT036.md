# PT036 TYPE|TRAIT|IMPL (micro test)

### NXD Sample:

```nxd
MODULE TEST

TYPE PERSON STRUCT:
    NAME: string

TRAIT DISPLAYABLE:
    FUNC DISPLAY()

IMPL DISPLAYABLE FOR PERSON:
    FUNC DISPLAY()
        PRINTLN("PERSON")

FUNC MAIN()
    PRINTLN("TRAIT_IMPL_TEST")
```
