# PT026 GT LT

### NXD Sample:

```nxd
MODULE TEST

FUNC MAIN()
    CONST LOW SET 3
    CONST HIGH SET 9

    IF HIGH GT LOW AND LOW LT HIGH:
        PRINTLN("RANGE_PASS")
```
