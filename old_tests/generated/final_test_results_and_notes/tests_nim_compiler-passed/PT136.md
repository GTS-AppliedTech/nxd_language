# PT136

### NXD Sample:

```nxd
MODULE TEST

TYPE PERSON STRUCT:
    NAME: string

TRAIT DISPLAYABLE:
    FUNC DISPLAY()

IMPL DISPLAYABLE FOR PERSON:
    FUNC DISPLAY()
        PRINTLN("PERSON")

FUNC MAIN()
    LET P SET PERSON
    CALL STRINGABLE.DISPLAY(P)
```
