# NXD Language

Official Visual Studio Code language support for the NXD programming language.

## Features

- .nxd file recognition
- .nxd source code file icons
- Syntax highlighting
- Keywords
- Types
- Strings
- Numbers
- Comments
- Diagnostics
- LSP Support

## Roadmap

- Hover documentation
- Go To Definition
- Generic Constraints (NXD-S3003)
- Async Runtime
- .nxd tooling/configuration file icon
- .nxd generated artifacts file icon
