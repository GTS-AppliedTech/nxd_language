# PT025 MOD NEQ EQ

### NXD Sample:

```nxd
MODULE TEST

FUNC MAIN()
    CONST A SET 10
    CONST B SET 3
    CONST C SET 0

    IF A MOD B NEQ C OR C EQ 0:
        PRINTLN("MOD_OR_PASS")
```
