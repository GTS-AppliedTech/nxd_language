# PT026 GT LT

### NXD Sample:

```nxd
MODULE TEST

FUNC MAIN()
    CONST LOW SET 3
    CONST HIGH SET 9

    IF HIGH GT LOW AND LOW LT HIGH:
        PRINTLN("RANGE_PASS")
```

### Result:

COMPILER: PASS
SEMANTICS:PASS

Expected Output:

### Actual Output:

```nim
# test


proc main() =
  let low = 3
  let high = 9
if high > low and low < high:
    println("RANGE_PASS")
```
