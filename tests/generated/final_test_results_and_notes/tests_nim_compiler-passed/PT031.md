# PT031 READY | MATCH | WAIT | HOLD

### NXD Sample:

```nxd
MODULE TEST

FUNC MAIN()
    CONST STATE SET "READY"

    MATCH STATE:
        CASE "READY":
            PRINTLN("GO")

        CASE "WAIT":
            PRINTLN("HOLD")

        OTHERWISE:
            PRINTLN("UNKNOWN")
```
